# PadChat compatibility

Preview 14 supports WoW Forever 1.60.x on Windows 10/11 x64, Interface 16001. Current checked client: 1.60.1.70888; Gethe/wow-ui-source Forever ref 4cd0ab752a77164f654ccbca9d0c1fe8dafceebe. Preview 13's chat/gamepad/bindings/secure send/invite audit remains applicable; this release changes companion startup and matching packaging only.

The launcher validates the selected client folder and actual running executable version. `_forever_/Wow.exe` is supported; only version-checked legacy Forever `WowB.exe` is retained. Retail, Classic and experimental multi-client support are not enabled.

Source and isolated process tests do not prove live gameplay or reboot behaviour on every PC. No clean second PC was available. A user confirmed the separately repaired personal companion works again; the public launcher still needs wider live acceptance. Install both matching parts for voice. CurseForge alone cannot install or start the companion.
