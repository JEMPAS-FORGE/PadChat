# PadChat compatibility

Preview 17 targets WoW Forever 1.60.1.71037 and addon interface 16001 on Windows 10/11 x64. Audited against Gethe Forever source `734f065329cff4992835b01a84f210a297db91b6`. The installer recognises version-checked Forever Wow.exe and older Forever WowB.exe. Live gameplay, physical controller input and reboot were outside the automated checks.
